# Aplikasi Putusan PN Banjarbaru

Aplikasi Java untuk mengelola data putusan perkara narkotika
Pengadilan Negeri Banjarbaru.

## Fitur
- Import 50 data putusan dari CSV
- Menampilkan seluruh data putusan
- Menambah dan menghapus data
- Pencarian data putusan
- Filter data putusan
- Statistik dan agregasi
- Pengurutan berdasarkan vonis
- Audit aktivitas menggunakan Stack
- Ekspor laporan TXT dan CSV

## Struktur Data
- Generic Singly Linked List
- Generic Stack

## Teknologi
- Java
- IntelliJ IDEA
- Git dan GitHub

## Dataset
50 data putusan perkara narkotika dalam format CSV.

## Cara Menjalankan
Buka proyek menggunakan IntelliJ IDEA,
kemudian jalankan class Main.java.
